# Elisa Gizzo, LMFT

Website for Elisa Gizzo, Licensed Marriage & Family Therapist based in New York. Built as a static HTML/CSS/JS site from a Claude Design handoff.

## Pages

| File | Description |
|---|---|
| `index.html` | Main landing page |
| `styles.css` | Shared stylesheet |

## Sections (index.html)

1. **Hero** — Full-viewport dreamy hero with atmospheric overlay and CTA
2. **About** — Elisa's bio, credentials, and stats
3. **Services** — Individual, Couples, and Family Therapy cards
4. **Philosophy** — Holistic approach statement
5. **Process** — 3-step "How we'll work together" flow
6. **Quote** — Albert Camus pull quote
7. **Story** — Client story feature with parallax photo
8. **CTA** — Call to action with booking link
9. **FAQ** — Accordion with 6 common questions
10. **Footer** — Newsletter signup, nav links, contact, legal

## Design

- **Fonts**: Cormorant Garamond (display), Manrope (body) via Google Fonts
- **Palette**: Sage green + warm cream — see CSS tokens in `styles.css`
- **Images**: Unsplash stock; Elisa's portrait pulled from her Squarespace CDN with an Unsplash fallback
- **Inspiration**: [ClearPath Framer template](https://clearpath-template.framer.website/)

## Running locally

```bash
python3 -m http.server 3456
# → http://localhost:3456
```

## Deployment

Static files only — deploy to any host (Netlify, Vercel, GitHub Pages, Squarespace, etc.) by pointing it at this repo root.
